# Куда пойти — Москва глазами Артёма

Сайт-карта с интересными местами Москвы. Пользователь открывает карту, кликает по точкам и смотрит фотографии и описание каждого места во всплывающей панели.

Учебный проект курса [Django на Devman](https://dvmn.org/modules/django/). Бэкенд на Django отдаёт точки в формате GeoJSON и подробности по каждому месту в JSON; фронтенд (Leaflet + сайдбар) рисует карту и всплывающие карточки.

## Что внутри

* Django 5.2
* SQLite (по умолчанию для разработки)
* [django-admin-sortable2](https://github.com/jrief/django-admin-sortable2) — сортировка фотографий в админке перетаскиванием
* [django-tinymce](https://github.com/jazzband/django-tinymce) — WYSIWYG-редактор для полного описания места
* Pillow — обработка загружаемых изображений
* Leaflet + [leaflet-sidebar](https://github.com/turbo87/leaflet-sidebar) на фронтенде

## Как запустить проект локально

1. Скачайте код:
   ```bash
   git clone https://github.com/KillReal11/where_to_go.git
   cd where_to_go
   ```

2. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv venv
   source venv/bin/activate      # Linux / Mac
   venv\Scripts\activate         # Windows
   ```

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Создайте в корне проекта файл `.env` со своими значениями:
   ```
   SECRET_KEY=укажите_свой_секретный_ключ
   DEBUG=True
   ALLOWED_HOSTS=127.0.0.1,localhost

5. Примените миграции:
   ```bash
   python manage.py migrate
   ```

6. Создайте суперпользователя, чтобы попасть в админку:
   ```bash
   python manage.py createsuperuser
   ```

7. Запустите сервер разработки:
   ```bash
   python manage.py runserver
   ```

8. Откройте в браузере:
   * сайт — [http://127.0.0.1:8000/](http://127.0.0.1:8000/)
   * админка — [http://127.0.0.1:8000/admin/](http://127.0.0.1:8000/admin/)

Свежая база данных пуста, поэтому карта сначала будет пустой — добавьте несколько мест через админку (см. ниже), чтобы увидеть точки на карте.

## Как наполнить сайт местами (админка)

1. Зайдите в `/admin/` под своей учётной записью.
2. Откройте раздел **Места** → **Добавить место**.
3. Заполните название, краткое и полное описание (полное описание редактируется в WYSIWYG-редакторе), укажите широту и долготу.
4. Ниже, во вкладке с картинками, загрузите одну или несколько фотографий места.
5. Порядок фотографий можно поменять простым перетаскиванием мышкой — новый порядок сохраняется в базу автоматически.
6. Сохраните место — оно сразу появится точкой на карте на главной странице.

Чтобы отредактировать существующее место, откройте список **Места**, найдите нужное по названию через поиск и зайдите в него — редактирование текста и фотографий устроено так же, как при добавлении.

Отдельный раздел **Картинки** в админке нужен только для отладки и не предназначен для повседневной работы с контентом — добавлять и менять фотографии удобнее прямо со страницы места.
